When you pass an image into a neural network to get a prediction, the data flows from the input layer, through all the hidden layers, and finally out to the output layer. 

This left-to-right flow of information is called **Forward Propagation** (or the Forward Pass).

## The Math Behind the Magic

While drawing circles and lines is a great way to intuitively understand a neural network, a computer cannot literally draw circles. It uses **Linear Algebra**.

For any given hidden layer, computing the forward pass consists of two extremely simple steps:

1. **Linear Transformation**: Multiply the input vector $X$ by the layer's weight matrix $W$.
   $$ Z = W \cdot X $$
2. **Non-linear Activation**: Pass the result $Z$ through an activation function like ReLU to get the layer's output $A$.
   $$ A = \text{ReLU}(Z) $$

If there is a second layer, $A$ becomes the new $X$ for the next layer, and the process repeats until the end!
