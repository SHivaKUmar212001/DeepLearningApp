# Product

## Register

product

## Users
Students and beginners learning deep learning from scratch. They arrive curious but possibly intimidated by the math. Their context: studying at home or in a library, working through lessons sequentially or jumping to topics that interest them. The job to be done is building genuine intuition for neural networks through hands-on interaction, not passive reading.

## Product Purpose
DeepDive is a 54-lesson interactive deep learning course that teaches everything from basic linear algebra to diffusion models. Every concept is paired with a live visualization the learner can manipulate. Success looks like a student who finishes a lesson and can explain the concept to someone else because they watched it happen, not because they memorized a definition.

## Brand Personality
Bold, immersive, technical. The interface should feel like stepping into a working research lab, not watching a lecture. Confidence without arrogance. Depth without gatekeeping.

## Anti-references
- Generic online course platforms (Coursera, Udemy): boxy video-and-quiz layouts, corporate stock imagery, lifeless cards, progress bars as the only UI personality.
- Dry documentation sites (MDN, ReadTheDocs): no visual hierarchy beyond headings, monochrome, zero delight, content-dump layout.
- Overstimulating gaming UI: neon overload, constant particle effects, motion that competes with the actual content, style over substance.

## Design Principles
1. **Teach through interaction, not decoration.** Every visual element either explains a concept or gets out of the way. Animations serve comprehension, not spectacle.
2. **Respect the learner's focus.** Dark, low-distraction surfaces. Generous whitespace around interactive widgets. Typography sized for sustained reading.
3. **Show the machine.** Expose the math, the gradients, the weights. The UI should make the invisible visible, like an X-ray of a neural network.
4. **Confidence through clarity.** Complex topics presented with calm authority. No dumbing down, no "just trust me." Every step earnable.
5. **Progressive density.** Early lessons feel spacious and inviting. Advanced lessons can be denser. The interface adapts to the learner's growing comfort.

## Accessibility & Inclusion
- Target WCAG 2.1 AA compliance.
- All interactive visualizations must have text alternatives or aria-live descriptions of state changes.
- Respect prefers-reduced-motion: particle effects and canvas animations should degrade to static states.
- Ensure 4.5:1 contrast ratio on all body text; 3:1 on large text and UI controls.
- Color is never the only way to convey information (difficulty levels use text labels alongside color dots).
